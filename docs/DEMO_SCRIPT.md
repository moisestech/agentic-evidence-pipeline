# Demo script (target)

Record only after the offline fixture demo and tests exist.

## 75–90 second narrated demo

1. **0:00–0:15** — Problem: assessments need citations, review, and an audit trail—not a chatbot.
2. **0:15–0:35** — Start seeded assessment; show sources becoming evidence IDs.
3. **0:35–0:50** — Hybrid retrieval returns control + evidence; typed assessment pauses at `needs_review`.
4. **0:50–1:05** — Approve or edit; open event timeline (prompt version, citations, latency, cost, hashes).
5. **1:05–1:25** — Failure: fabricated citation blocked; routed to review.
6. **1:25–1:30** — Point to evidence map and offline eval command.

## README loop (18–25 seconds)
